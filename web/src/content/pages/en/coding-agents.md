You can use your own laptop and your usual development setup. If you would
rather work in a ready-to-use environment, you can select our development and
AI add-ons when registering for the hackathon.

You will receive the access codes for the add-ons described below when you
arrive. Both add-ons are optional, but you must select them during registration;
they cannot be added later.

## Hosted development environment

The hosted development environment is a complete programming environment that
opens directly in your web browser. You can edit files, run terminal commands,
install packages, and preview your app without first setting up development
tools on your own computer. The environment is hosted in Austria and includes
[pi.dev](https://pi.dev), a preinstalled AI coding assistant.

The environment is optional and must be selected during registration. Because
the preinstalled assistant requires access to an AI model, you must also select
the AI API add-on described below.

## AI API access

The optional AI add-on provides an OpenRouter API key with access to **Mistral
Medium 3.5** and a **$20 usage budget per attendee**. You can use the API key in
the hosted environment or with compatible tools in your own setup. You may
select the AI add-on without the hosted environment, but the hosted environment
is only available together with the AI add-on.

Prefer a different model or provider? You are welcome to use your own model
access and cover the associated costs yourself. The hackathon budget applies
only to the provided access to Mistral Medium 3.5.
