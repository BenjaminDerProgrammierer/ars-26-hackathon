# Example Projects

This folder contains example projects built with the hackathon datasets, similar
to what a participant might create during the event.

Use these projects as inspiration, as references for working with the data, or as
starting points for your own ideas.

## Projects

- [Who Comes to Linz?](who-comes-to-linz/) — compare countries represented by
  public festival contacts with the origins recorded in Linz's 2024 guest
  statistics.
- [Mind the Gap // Linz](mind-the-gap/) — turn the interval between two
  festival events into a short encounter with a nearby city tree.
- [What's Close? // Linz](whats-near-me/) — a browser-only nearby-place
  explorer built with Vite and TypeScript.
- [GPS Art Maker // Linz](gps-art-maker/) — upload a picture and turn its
  silhouette into a walkable GPS-art route with a GPX export.
