# Example Projects

This folder contains example projects built with the hackathon datasets, similar
to what a participant might create during the event.

Use these projects as inspiration, as references for working with the data, or as
starting points for your own ideas.

## Projects

- [Minimaler Festival-Kalender](pi-dev-calendar/) — a deliberately small Vite
  and plain TypeScript example used in the pi.dev tutorial.
- [Festival Day Weaver // Linz](festival-day-weaver/) — assemble a feasible
  festival itinerary with transfer estimates, departure prompts, public
  transport queries, drinking-water stops, and toilets.
- [What's Close? // Linz](whats-near-me/) — a browser-only nearby-place
  explorer built with Vite and TypeScript.
- [Ars Festival RAG Search](2026-08-04-rag-example/) — an inspectable
  command-line example of semantic search and sourced answers over public
  festival projects.
